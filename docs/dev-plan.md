## 데이터 모델 (Firestore)

```
/schools/{schoolId}/
  ├─ students/{studentId}
  │    학년, 반, 번호, 이름, 이메일, 학번
  │    electiveSubjects: [과목명, ...]   ← 수강 선택과목 목록
  │
  ├─ subjects/{subjectId}
  │    name, grade, type(common|elective)
  │    hasExam, isEssay, duration(분)
  │
  ├─ rooms/{roomId}
  │    name, capacity
  │
  └─ plans/{planId}
       name                             ← '2026 1학기 중간고사'
       examDays: [{date, label, periods:[{id, startTime, duration}]}]
       sessions: [{
         subjectId, subjectName, grade, type,
         dayId, periodId,
         roomAssignments: [{roomId, studentIds:[...]}]
       }]
```

## 개발 단계

### ▶ Stage 1. 기초 데이터 입력 시스템
_우선순위 최고 — 이게 없으면 이후 모든 작업 불가_

#### 1-1. 학생 명렬 관리
- [ ] CSV/엑셀 업로드 파서 (선택과목 컬럼 수 동적 처리)
- [ ] 학년별 학생 목록 테이블 (페이지네이션)
- [ ] 개별 학생 추가 / 수정 / 삭제
- [ ] 학번 중복 검사

#### 1-2. 고사실 설정
- [ ] 고사실 목록 CRUD (이름, 최대인원)

#### 1-3. 과목 목록 관리
- [ ] 과목 등록 (이름, 학년, 공통/선택, 서술형 여부, 시험시간)
- [ ] 과목별 고사 여부 설정 (이번 고사에 시험 볼 과목 선택)
- [ ] 과목별 응시 인원 자동 집계 (학생 명렬 기반)

---

### ▶ Stage 2. 시험 계획 수립

#### 2-1. 고사 기간 설정
- [ ] 고사명 입력 (예: 2026 1학기 중간고사)
- [ ] 시험 날짜 선택 (최대 5일)
- [ ] 교시별 시작시간 / 시험시간 설정

#### 2-2. 일정 배치
- [ ] 과목 카드 → 날짜/교시 슬롯 드래그 배치
- [ ] 실시간 충돌 감지 (중복 응시, 3연속 경고)
- [ ] 1~3학년 통합 시각화
- [ ] 미배치 과목 표시

#### 2-3. 고사실 배정
- [ ] 배치 확정 과목별 응시자 자동 배정 (학번순, 최대인원)
- [ ] 고사실 분배 로직 (초과 시 다음 고사실)
- [ ] 배정 결과 수동 조정

---

### ▶ Stage 3. 출력물 생성
_양식 확정 후 개발_

- [ ] 시험시간표 HTML 렌더링 + 인쇄
- [ ] 개인별 시험고사실 안내문
- [ ] 고사실별 응시 명렬 + 좌석배치도
- [ ] 학급별 명렬표
- [ ] PDF 저장 / 엑셀 내보내기

---

### ▶ Stage 4. 감독교사 편성
_추후 개발 — 탭만 생성_

- [ ] 탭 UI 플레이스홀더

## 화면 구성 (탭 구조)

```
[기초 데이터]
  학생 명렬 | 고사실 | 과목 설정

[시험 계획]
  고사 기간 설정 | 일정 배치 | 고사실 배정

[감독 편성]   ← '준비 중' 표시

[출력물]
  시험시간표 | 개인별 안내 | 고사실 명렬 | 학급별 명렬
```
