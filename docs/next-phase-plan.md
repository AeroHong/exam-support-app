## 1. 고사실별 응시 현황표 ⭐ 최우선

### 출력 형식
**PDF** (인쇄 후 고사실 비치용)

### 필수 정보 구성

#### 헤더
- 고사일 (예: 2024년 5월 16일 목요일)
- 고사 교시 및 시간 (예: 1교시 08:30 - 09:20)
- 고사실 (예: 3-2 교실)
- 과목명 + **과목코드** (예: 확률과 통계 [MA101])

#### 응시 인원 요약
```
재적인원: 35명 (응시 30 + 도움실 3 + 별도실 2)
응시인원: 30명
도움실: 3명
별도실: 2명
```

#### 좌석 배치표 (테이블)
| 좌석번호 | 학번 | 이름 | 성별 | 결시 |
|----------|------|------|------|------|
| 1 | 30101 | 홍길동 | 남 | ☐ |
| 2 | 30102 | 김철수 | 남 | ☐ |
| ... | ... | ... | ... | ☐ |

#### 별도 명단
- **도움실 응시 학생**: 30215 김OO, 30318 이OO, 30422 박OO
- **별도실 응시 학생**: 30110 최OO, 30205 정OO

#### 감독관 서명란
```
[ 1교시 감독 ]  _______________ (인)
[ 2교시 감독 ]  _______________ (인)
```

### 선행 작업 필요 ⚠️

**과목 코드 입력 기능 추가**
- `subjects` 컬렉션에 `subjectCode` 필드 추가 (현재는 선택 필드로만 존재)
- `SubjectsTab.jsx`에 과목코드 입력 UI 추가
- Excel 업로드 시 과목코드 컬럼 파싱

### 기술 스택 제안
- **jsPDF** + **jsPDF-autotable**: PDF 생성 및 테이블 레이아웃
- 또는 **react-pdf/renderer**: React 컴포넌트 기반 PDF 생성 (더 직관적)

## 4. 시험 운영 계획 보고서

### 출력 형식
**PDF** 또는 **Word** (.docx)

### 구성

#### 1) 표지
```
2024학년도 1학기 중간고사 운영 계획

OO고등학교
```

#### 2) 시험 개요
- 시험 기간: 2024년 5월 16일(목) ~ 5월 18일(토)
- 대상 학년: 2학년, 3학년
- 총 과목 수: 45개
- 총 세션 수: 120개

#### 3) 과목별 고사 운영 정보 (테이블)
| 과목명 | 학년 | 시험일 | 교시 | 시간 | 형태 | 응시인원 | 고사실 |
|--------|------|--------|------|------|------|----------|--------|
| 국어 | 3 | 5/16(목) | 1교시 | 08:30-09:20 | 선택형 | 280 | 3-1~3-8 |
| 수학I | 3 | 5/16(목) | 2교시 | 10:00-10:50 | 서논술형 | 140 | 수학실1,2 |
| ... | ... | ... | ... | ... | ... | ... | ... |

#### 4) 일정표 (시간표 형식)
```
┌──────────┬──────────┬──────────┬──────────┐
│          │ 5/16(목) │ 5/17(금) │ 5/18(토) │
├──────────┼──────────┼──────────┼──────────┤
│ 1교시    │ 국어(280)│ 영어(280)│ 사회(120)│
│ 08:30    │ 3-1~3-8  │ 3-1~3-8  │ 3-1~3-4  │
│          │ 대기 15  │ 대기 15  │ 대기 165 │
├──────────┼──────────┼──────────┼──────────┤
│ 2교시    │ 수학I(140)│...      │ ...      │
│ 10:00    │ 수학실1,2│          │          │
│          │ 대기 145 │          │          │
└──────────┴──────────┴──────────┴──────────┘
```

#### 5) 특이사항
- 도움실 운영 일정
- 별도실 운영 일정
- 감독 교사 배정 현황 (향후 추가 가능)

### 기술 스택 제안


### 기술적 도전 과제

1. **대량 PDF 생성 성능**
   - 학생 280명 → 280개 페이지 PDF 생성
   - 브라우저 메모리 제한 고려
   - 진행 상황 표시 필요

2. **개인별 데이터 필터링**
   - 각 학생의 수강 과목 (`enrollments`)
   - 해당 과목의 세션 정보 (`sessions`)
   - 배정된 고사실 정보 (`roomIds`)
   - 대기 시간 계산

3. **일괄 다운로드 방식**
   - 옵션 1: 단일 PDF에 모든 학생 포함 (용량 큼)
   - 옵션 2: ZIP 파일로 개별 PDF 묶음
   - 옵션 3: 학급별로 분할 생성

### 기술 스택 제안
- **react-pdf/renderer**: React 컴포넌트로 PDF 템플릿 작성
- **jszip**: 개별 PDF를 ZIP으로 묶어 다운로드
- **Web Worker**: 백그라운드에서 PDF 생성하여 UI 차단 방지

## 공통 기술 요구사항

### 1. PDF 생성 라이브러리 선택

#### 옵션 A: jsPDF + jsPDF-autotable
**장점:**
- 가볍고 빠름
- 테이블 생성에 최적화
- 한글 폰트 지원 가능

**단점:**
- 명령형 API (코드 복잡도 증가)
- 복잡한 레이아웃은 구현 어려움

**추천 용도:** 고사실 응시 현황표, 대기실 명렬표

#### 옵션 B: react-pdf/renderer
**장점:**
- React 컴포넌트 기반 (선언적)
- 복잡한 레이아웃 구현 용이
- 프리뷰 기능 쉬움

**단점:**
- 번들 크기 증가 (약 500KB)
- 한글 폰트 추가 설정 필요

**추천 용도:** 학생 개인별 시간표, 시험 운영 계획 보고서

### 2. Excel 생성 (선택적)

**xlsx-js-style** 또는 **exceljs**
- 셀 스타일, 병합, 테두리 등 지원
- 학급별 명렬표는 Excel이 더 편리할 수 있음

### 3. 한글 폰트 처리

PDF 생성 시 한글 깨짐 방지:
```javascript
// jsPDF 예시
import { jsPDF } from "jspdf";
import "jspdf-autotable";
import NanumGothic from "./fonts/NanumGothic-normal.js"; // Base64 인코딩

const doc = new jsPDF();
doc.addFileToVFS("NanumGothic.ttf", NanumGothic);
doc.addFont("NanumGothic.ttf", "NanumGothic", "normal");
doc.setFont("NanumGothic");
```
