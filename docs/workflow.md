# 고사업무 지원앱 워크플로우

## 개요

고등학교 1~3학년 전체 고사를 대상으로, 과목 확정부터 출력물 생성까지 전 과정을 웹앱에서 처리한다.
작업량이 많고 실수가 발생하기 쉬운 구조이므로, 자동화와 오류 감지를 핵심 목표로 설계한다.

---

## 학년별 특성

| 학년 | 과목 구성 | 응시 단위 |
|------|----------|----------|
| 1학년 | 공통과목만 (선택과목 없음) | 학급 단위 (반 전체 동일 과목) |
| 2학년 | 공통과목 + 선택과목 (최대 5과목) | 공통: 학급 단위 / 선택: 수강자 혼합 |
| 3학년 | 공통과목 + 선택과목 (최대 8과목) | 공통: 학급 단위 / 선택: 수강자 혼합 |

- 선택과목 수는 매년 달라질 수 있음
- 선택과목이 모두 시험을 보는 건 아님 → 과목별 고사 계획에 따라 시험 여부 결정

---

## 기초 데이터 입력 양식

### 학생 명렬 업로드 컬럼

**1학년**
```
학년 | 반 | 번호 | 이름 | 학교계정
```

**2학년**
```
학년 | 반 | 번호 | 이름 | 학교계정 | 선택과목1 | 선택과목2 | 선택과목3 | 선택과목4 | 선택과목5
```

**3학년**
```
학년 | 반 | 번호 | 이름 | 학교계정 | 선택과목1 | 선택과목2 | 선택과목3 | 선택과목4 | 선택과목5 | 선택과목6 | 선택과목7 | 선택과목8
```

- 선택과목 컬럼 수는 매년 다를 수 있으므로, 업로드 시 동적으로 처리
- 선택과목 셀이 비어 있으면 해당 과목 없음으로 처리
- 업로드 후 개별 수정/삭제 가능 (전출, 자퇴, 퇴학 등 대응)

### 고사실 설정

- 고사실명, 최대 수용 인원 등록
- 좌석은 1번~최대인원 번호로 고정
- 배정 시 학번순으로 1번 좌석부터 채움

## 단계별 워크플로우

### Phase 0. 기초 데이터 설정 (학기 시작 시 최초 1회)

1. 학생 명렬 업로드 (학년별)
2. 고사실 설정 (고사실명, 최대인원)
3. 과목 목록 입력 (공통/선택 구분, 학년, 서술형 여부, 시험시간)

---

### Phase 1. 고사 과목 확정

- 등록된 과목 중 이번 고사에서 시험을 볼 과목 선택
- 각 과목 속성 확인:
  - 학년 (1 / 2 / 3학년)
  - 공통과목 (전 학급 응시) vs 선택과목 (수강자만 응시)
  - 서술형 포함 여부
  - 시험 시간 (분)
- 확정 후 과목별 응시 인원 자동 집계

---

### Phase 2. 시험 일정 배치

#### 핵심 제약 조건
- 동일 학생이 같은 교시에 두 과목 응시 불가
- 단, 묶인 두 과목의 수강자가 완전히 겹치지 않으면 같은 교시 배치 가능
- 1~3학년 전체를 동시에 고려

#### 배치 작업
- 고사 기간 설정 (날짜 선택, 통상 5일)
- 교시별 시작 시간 및 시험 시간 설정
- 과목을 날짜/교시 슬롯에 배치 (드래그 또는 선택)
- 실시간 오류 감지:
  - 동일 학생 동일 교시 중복 응시
  - 하루 3교시 이상 연속 응시 학생
  - 미배치 과목

---

### Phase 3. 고사실 배정

- 배치 확정된 과목별 응시자를 고사실에 배정
- 배정 방식:
  - 학번 순서대로 고사실 좌석 1번부터 최대인원까지 채움
  - 인원 초과 시 다음 고사실로 자동 분배
  - 고사실별 배정 인원 수동 조정 가능
- 서술형 과목은 별도 고사실 지정 가능

---

### Phase 4. 감독교사 편성 _(추후 개발)_

- 탭만 생성, 기능 미구현 상태로 대기

---

### Phase 5. 출력물 생성 _(양식 추후 확정)_

출력 형태: HTML 페이지 렌더링 + 인쇄 버튼 / PDF 저장 / 엑셀 내보내기

| 번호 | 출력물 | 내용 |
|------|--------|------|
| 1 | 시험시간표 | 날짜별/교시별 과목 배치 전체표 |
| 2 | 개인별 시험고사실 안내문 | 학생 개인별 시험 일정 + 고사실 + 좌석 번호 |
| 3 | 고사실별 응시인원 및 응시 명렬 | 고사실별 응시자 명단 (학번순) |
| 4 | 고사실별 선택과목 좌석배치도 | 고사실 좌석 시각화 (혼합 고사실용) |
| 5 | 학급별 인원 및 선택과목 고사 명렬 | 학급별 학생의 선택과목 응시 현황 |
| 6 | 학급별 고사실 명렬표 | 담임용: 학급 학생들의 고사실 배정 현황 |

## 주요 자동화 포인트

| 체크 항목 | 처리 방식 |
|----------|----------|
| 동일 학생 동일 교시 중복 응시 | 배치 시 실시간 경고 |
| 미배치 과목 존재 | 다음 단계 진입 차단 또는 경고 |
| 고사실 정원 초과 | 배정 시 실시간 표시 |
| 하루 3교시 이상 연속 응시 | 대시보드 경고 |
| 기초 데이터 미입력 상태 진입 | 단계 진입 차단 |
